# University

Учебные проекты и лабораторные работы.

- [API_1 — проектирование и реализация REST API](API_1/README.md): Go, chi, zap,
  SQLite; проекты и задачи, версии API, идемпотентность, rate limiting и Swagger.
- [API_2 — продвинутые принципы REST API](API_2/README.md): продолжение первой
  работы; выбор полей через include, пагинация v2 и внутренний API статистики
  с отдельным ключом доступа.
- [Client_3 — клиент чужого Library API](Client_3/README.md): интерактивное меню
  на Go, каталог книг, авторизация читателя, выдача и возврат.
- [Broker_4 — API через RabbitMQ](Broker_4/README.md): проекты и задачи,
  версии v1/v2, CLI-клиент, транзакционная идемпотентность, retry и DLQ.

Инструкция запуска и примеры запросов находятся в README соответствующего проекта.
Локальные настройки с ключами, базы данных и бинарники в репозитории не хранятся.
